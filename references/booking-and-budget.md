# 预订节奏与预算优化

> 本文件是**行程之外的事务层**：什么时候订什么、怎么订更省、签证与保险要提前多久。
>
> 与 `planning-rules.md` 的分工：**那边管「行程本身排得对不对」（里程/海拔/强度/多人），这里管「行程之外的期限与账」**。
> 规划阶段两者都要过一遍，但别把内容混着写——质疑归质疑，预算归预算。

## 1. 行前倒计时（按出发日倒排）

规划完成、日期确认后，按出发日倒排检查下列节点。**本 skill 不做持续跟踪**（无长期记忆），
所以做法是：**把与本次行程相关的节点写进路书的 `tips[]`**，让用户在自己手机上看到。

| 提前量 | 要办的事 | 说明 |
|---|---|---|
| **T-90 天** | 复杂签证；多人/团体机位 | 需面签或录指纹的目的地（申根、美、英、加、澳），部分国家预约排期很长；团体票要提前锁位 |
| **T-60 天** | 国际机票；**含既往症的旅行保险** | 国际机票的价格甜点区；保险在首次付款后 14 天内买才覆盖既往症（见 §5） |
| **T-45 天** | 酒店；普通签证；多人租车 | 普通旅游签（日/韩/东南亚电子签等）留够 30–45 天；旺季酒店此时开始紧张 |
| **T-30 天** | 门票预约、区间车、限流景区；餐厅 | 国内 5A 与热门馆多需实名预约；热门餐厅开放预订即抢 |
| **T-14 天** | 普通旅行保险；随行儿童证件复核 | 儿童证件、部分国家的同意书要求 |
| **T-7 天** | 银行/支付通知；打包定稿；值机提醒 | 境外用卡提前告知银行；证件复印件与电子备份 |

> **出境行程额外前置**：护照有效期须 ≥ 返程日 + 6 个月（多数国家硬性要求），换发护照本身要 6–8 周。
> 这条**必须在 T-90 之前确认**，否则整条行程不成立。

## 2. 预订时机窗口

| 类别 | 建议窗口 | 原因 |
|---|---|---|
| 国际机票 | **提前 3–4 个月** | 相对临期可省 10–20% |
| 国内机票 | **提前 6–8 周** | 价格甜点区，过早过晚都贵 |
| 酒店 | **提前 2–3 个月** | 选择最全 + 多含免费取消 |
| 租车 | **提前 2–6 周** | 价格波动小；多数可免费取消，跌了重订 |
| 活动 / 演出 / 热门馆 | **提前 2–4 周** | 热门的更早售罄 |
| 餐厅（尤其fine dining） | **提前 1–4 周** | 越高端越要早 |

**星期效应**：机票周二下午通常需求最低；酒店周末普遍加价 10–15%；租车工作日取还比周末便宜。

## 3. 平季与旺季

- **平季（相对旺季省 30–40%）**：国内大致是 **4–5 月、9–10 月**（避开五一与国庆头尾）。
- **旺季（加价 80–120%）**：**春节、国庆、暑假 7–8 月**；清明/五一/端午的短假也有局部高峰。
- **本地因素会显著影响价格**：目的地本地的节庆、大型会议/展会、马拉松等，会让当地酒店短期跳涨。
  **规划时查一下目的地当周有没有大型活动**，这比看季节更准。

> 与 `planning-rules.md` §4 的关系：那边讲「怎么错峰排行程」（哪天出发、避堵），
> 这里讲「什么时候该下单」。两者配合：**先定错峰日期，再按 §2 窗口下单**。

## 4. 省钱战术

**机票**
- 日期灵活 ±3 天，常能省 20–40%——如果用户日期没定死，**把「弹性日期」作为建议给出去**。
- 邻近机场（如上海 vs 杭州、广州 vs 深圳）有时便宜 30%+，代价是地面接驳时间。
- 分开买（两段单程）有时比往返便宜；但**要自己承担衔接风险**，联程才有航司保护。
- 里程/积分先查再用现金。

**酒店**
- 直接订有时与 OTA 同价但权益更好；会员价通常 10–15% off（注册免费）。
- 预付价便宜 15–20%，但**不可退**——行程未定死时不要选。
- 连住优惠：不少酒店第 5 晚 / 第 7 晚免费。

**租车**
- **避开机场门店**：机场取车普遍加价 30–40%，市区门店更便宜。
- **同地还车**：异地还车费很贵，尽量环线回到原点。
- 多数租车可免费取消，**价格跌了就重订**。
- 先看信用卡是否已含租车险，再决定要不要买。

**支付与汇率**
- 出发前只换 20% 左右的现金，其余到当地 ATM 取（汇率通常优于兑换点）。
- **避开机场兑换**，汇率差 5–8%。
- 用免货币转换费的卡；记录每笔用的汇率，便于预算对账。

## 5. 签证与保险提前量

| 类型 | 提前量 | 说明 |
|---|---|---|
| 免签 / 电子签（ESTA、eTA 类） | 1–2 周 | 也要留审核时间，别卡最后 |
| 普通旅游签 | 30–45 天 | 多数国家 |
| 复杂签证（需面签/录指纹） | **90 天以上** | 预约排期是瓶颈，不是审核 |
| 护照换发 | 6–8 周 | 常规办理 |

**护照有效期铁律**：多数国家要求**返程日之后仍有 6 个月有效期**。订票前先查。

**保险时机**
- **首次付款后 14 天内投保** → 通常可覆盖既往症。
- 超过 14 天 → 既往症可能被除外。
- 保费约为行程总价的 4–6%，含高风险活动（徒步/骑行/滑雪）再加 2–4%。

> `planning-rules.md` §11 讲出境要**带**什么（护照、签证、IDP、境外保险），
> 本节讲这些东西要**提前多久办**。两处不重复。

## 6. 多城市与跨境衔接

**最小停留**（避免「一晚过境」把人拖垮）

| 总行程 | 每城最少住 | 理由 |
|---|---|---|
| 1 周 | 2 晚 | 低于此只剩赶路 |
| 2 周 | 3 晚 | 才有时间看 |
| 3 周以上 | 3–4 晚 | 深度 |

> **一晚停留只允许出现在「纯过境」或「途中休息」**，且要在 `decisions[]` 里写明理由。

**开口程（open-jaw）**：A 城进、B 城出。常与往返同价，但省掉一段内陆交通 + 一整天折返时间。
**多城市行程应主动检查是否适用**——这是最容易漏掉的一笔省钱与省时。

**衔接缓冲**（低于此值要标风险）

| 衔接类型 | 最小缓冲 |
|---|---|
| 国际航班转国际 | 4 小时 |
| 国内航班转国内 | 2 小时 |
| 火车同站换乘 | 30–45 分钟 |
| 火车跨站换乘 | 1.5 小时 |
| 飞机 → 火车 | 3 小时 |

> 补充 `planning-rules.md` §11 的口径：**不直挂行李的中转要在上表基础上再加 1.5–2 小时**
> （取行李 + 重新值机 + 再过安检）。表里的值假设行李直挂。

**每 3 城留 1 个「慢日」**：不排景点、睡到自然醒、处理洗衣与补给。这条与
`planning-rules.md` §10 的「骑行每 5–7 天一个完整休息日」是同一逻辑，只是适用面更广。

## 7. 出行前确认清单

订完之后立刻把下列信息集中记一处。**要用户逐项做完的动作写进 `checklist[]`**（路书里渲染成可勾选清单，勾选状态存在用户手机本机，见 `roadbook-spec.md`）；需要知道但不用勾的说明仍写 `tips[]`；同一句不两处写。§1 倒计时里与本次行程相关的节点，也按 `when: "T-30"` 这类时点标签落进 `checklist[]`。

- 确认号 / 订单号（**路书里只写后四位**，完整号码不落盘，见 `roadbook-spec.md`「字段来源标注」）
- 日期与时间（**跨时区要写清是哪个时区的当地时间**）
- 地址与联系电话
- 取消/改签政策
- 付款方式

**关键凭证要截图或打印**——境外不一定能随时联网查邮箱。用户把这些截图或邮件交回来时，按 SKILL.md §2「订单截图 / 邮件识别」抽取并确认后再写入 `flights[]` / `stays[]`。
**托运行李按「可能延误 24 小时」准备**：证件、药品、充电器、一套换洗衣物放随身。
