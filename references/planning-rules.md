# 行程合理性校验规则

拿到用户的初步想法或现成行程表后，**先质疑、再规划**。用户往往低估里程、忽略海拔与节假日车流。以下规则逐条核对，发现问题要明确指出并给替代方案（附里程对比），不要默默照做。

## 1. 里程与驾驶时长（自驾）

- **所有路段必须用高德驾车规划实测**（见 amap-tools.md），禁止采用用户表格数字或直线距离。
- 节奏阈值（按单日纯驾驶时间）：
  - 赶路日（去程/返程）：建议 ≤ 750km / ≤ 8h；超过要在路书中标注"长日"并给早出发时间。
  - 慢游日：100–300km，半天开车半天玩。
  - 单人驾驶每 2 小时休息 15 分钟；全程尽量不赶夜路，尤其山区。
- 行程末日若必须超长（如赶回上班），安排 6:00–6:30 出发、服务区多停，并在注意事项里单列。
- 检查每天里程是否均衡：出现"某天 800km、次日 80km"的极端搭配，优先重新选择过夜中点。

## 2. 过夜中点的选择

- 中点应在主通道上、城市设施齐全（加油/住宿/医疗）。
- 去高原时，中点兼顾**海拔阶梯**：如先住海拔约 1900m 的城市适应一晚，再上 3000m+。
- "绕远"要用数据判断：把"用户方案"与"直觉顺路线"分别实测总里程对比。看似绕路的中点可能总里程更短（实例：南宁→曲靖→香格里拉 1414km，比南宁→昆明→香格里拉 1490km 还省 76km），结论要给数字而非感觉。

## 3. 高原与特殊环境

- 抵达海拔 3000m+ 首日：不安排高强度景区、不洗澡、早睡；路书写明高反症状与下撤原则。
- 4000m+ 景点（如普达措、牛奶海）安排在适应 1–2 天后。
- 提示备氧气罐、高反药（红景天提前数天服用）、防晒、唇膏、保暖。

## 4. 节假日与错峰

- 涉及法定节假日，先用 general_search 核实当年放假安排（国务院通知/政府网为准），算出需要请几天年假。
- 热门方向：假期首日上午出城高峰、末日返程高峰；建议假期前一天下午错峰出发、末日早出发。
- 热门景区（大理/丽江/亚丁等）国庆车流极大，路线选择可把"避堵"作为权重，并提示酒店尽早订。

## 5. "不想去 X 地"必须澄清两种含义

- **可过境不停留**：走最短主线，里程短。
- **完全绕开**：往往要换通道，里程代价可能达数百公里。
- 必须把两条线的实测里程都算给用户，由用户拍板；直觉上"绕开"的线未必更长，务必逐段实测，不要凭印象给里程差。实例（2026-09 深圳→香格里拉行程实测）：丽江（束河）返深圳，"经大理州/昆明方向"且含抚仙湖、罗平九龙瀑布景区绕行实测约 2008km，"绕开大理走攀枝花"（经元谋、石林、兴义）实测约 1955km，两线里程相近（差约 53km），并非南线更近。真正的取舍：G56/G80 南线国庆返程车流更大，但沿线湖、瀑游玩点更丰富、海拔下降平缓；G5 攀枝花线车流更小、气候干热、景点以土林为主——由用户按拥堵耐受度与游玩偏好拍板。

## 6. 环线与游玩密度

- 往返尽量走不同线路，增加沿途游玩面，避免回头路。
- 核心目的地停留天数与用户目的匹配：风光摄影给早晚光线时段，亲子/老人降低单日强度。
- 每天至少留一个"可选"景点（路书标注"可选"），允许体力或天气变化时砍掉。

## 7. 天气与门票前置核实

- 天气超出高德 4 天预报窗口的，按气候参考写并标注查询日期。
- 5A/热门景区（限流、实名预约、区间车另购）要在规划阶段查清：是否需预约、门票/区间车/索道价格、开放时间，写进门票模块与注意事项。

## 8. 非自驾变体

- **高铁/飞机 + 当地租车**：路书 `km` 字段改写成班次与时长（如"高铁 G2902 约 4h"），增加取还车点、租车证件提示；天气/路书/门票/穿着模块不变。
- **纯公共交通**：节点间写班车/客运班次与衔接风险，行李寄存、末班车时间写进贴士。

## 9. 出行主体与多人 / 多车

**先确认出行主体**（它决定整套强度与后勤）：

| 主体 | 关注点 |
|---|---|
| 独行 | 行程报备（留给家人）、疲劳自控、无分摊、安全备份 |
| 情侣 / 双人 | 司机数：1 人开车=严格限时；2 人=轮换 |
| 家庭（含儿童 / 老人） | 单日强度下调、午休、如厕/用餐频次、儿童安全座椅、老人高反与慢病、避开高强度徒步 |
| 朋友团 / 团建（多人多车） | 编队、对讲、集合点、费用分摊、分歧裁决、出泳道图 |

**多人多车自驾**（「多人自驾」）：
- **司机轮换**：长途每 2 小时换一次驾驶员；每车至少 2 名持证司机，绝不一人开到底。
- **副驾职责**：导航、盯路况、提醒车速、递水递食——不是玩手机位。
- **车队编队**：设头车 / 尾车；统一对讲频道或微信群；约定跟车不超速；复杂路口 / 岔路「前车等后车」。
- **集合点**：每段起点、服务区、目的地入口设明确集合点；**走散预案**（原地等待 or 直奔下一集合点）。
- **费用分摊**：油费 / 过路费 / 停车按车 AA；住宿 / 餐饮 / 门票按人；事先定谁垫付、用共享表格记账。
- **分歧裁决**：事先约定机制——主理人拍板 / 少数服从多数 / 分组行动后汇合；不要在路上临时吵。
- **分批抵达会合**：多人从不同城市 / 航班 / 车次抵达时，**首日不排长距离**；按「最晚抵达者」倒排当天行程并留会合缓冲。实例：一人昆明、一人喀什在重庆会合，若会合晚于 15:00，当天不硬推 200km，改为主城休整。
- **行李与限高**：多人行李多，注意后备箱 / 车顶箱容量；**装车顶箱后整车常近 2m，地库 / 限高杆易刮**。

**多人骑行**（「多人骑行」）：
- 编队按**能力最弱者**定速定程（不是按最快者）；设收尾（sweeper）确保无人掉队。
- 约定集合 / 补给点（每 20–30km）；走散预案；对讲或手机群。
- 车队间距与超车手势；夜间 / 隧道强制开灯。
- 人数多时按速度拆分小组，避免大队互相拖慢。

## 10. 人力 / 两轮变体（骑行 / 徒步 / 摩托）

（§8 已列高铁 / 飞机 + 租车、纯公交；本节补人力与两轮）

**骑行（自行车 / 电助力）**：
- **单日里程上限**（载重、多日）：新手 30–50km；有经验 50–80km；训练有素 80–120km；电助力 +30–50%。
- **爬升换算**：每 100m 累计爬升 ≈ 额外 1km 等效努力（例：60km + 1200m ≈ 按 72km 平路规划）。
  → **数据落点**：把爬升写进 `viz.route[].gain`（段累计爬升，米）、节点海拔写 `viz.route[].m`。
  下游会自动标出「等效 +Xkm」并推导海拔剖面；`elevation[]` 因此可省略。
  骑行/徒步行程**不给 `gain` 等于没做爬升核算**，属于必填。
- **路面折减**：砾石 / 烂路速度降 30–40%；雨天再降 30–40%；逆风可致均速腰斩；>30℃ 里程减 20–30%。
- **节奏**：>7 天行程每 5–7 个骑行日安排 1 个完整休息日；困难日后安排 30–50km 恢复段；抵达住宿 16:00–18:00。
- **后勤**：每 20–30km 设备用补给 / 撤离点（可接驳火车 / 大巴）；备内胎 / 补胎工具 / 打气筒；住宿须能安全停放或携带自行车；驼包重量 5kg vs 20kg 差异巨大。
- **安全**：头盔 / 尾灯 / 反光；避开无自行车道的快速路与长隧道。

**摩托**：禁摩路段、高速禁行、加油点间距；骑行服 / 护具；雨天与夜路风险高于汽车。

**徒步 / 背包**：单日 15–25km（重装 10–15km）；累计爬升与海拔优先于距离；每天留 1 个下撤点；水源 / 补给 / 露营或住宿点；高原徒步按 §3 阶梯适应。

**房车 / 包车**：房车看营地 / 加水加电 / 限高限宽 / 排污；包车看司机资质、费用含不含油过路、行程弹性。

> 数据来源：骑行单日里程与爬升换算据 Baroudeur Cycling「多日骑行每日公里数指南」；多人多车分工据汽车之家「多人家庭长途自驾方案」。均为经验区间，按实际体能/车型/路况下调。

## 11. 其他使用环境（按需启用）

- **无障碍 / 行动不便**：确认全程无障碍设施（电梯 / 坡道 / 无障碍卫生间）；避开台阶密集景区；轮椅 / 助行器的车辆运输与景区租借。
- **婴幼儿 / 孕妇**：行程留白、就近医疗点；避免高海拔与剧烈活动；孕晚期不出行。
- **宠物同行**：可携宠住宿、景区是否禁宠、疫苗 / 检疫证明、车内固定与安全带。
- **出境游**：护照有效期（≥6 个月）、签证 / 免签、汇率与支付方式、电话卡 / 漫游、驾照国际认证（IDP）、境外保险、时差与首日强度。
  - **时差必须落到具体时刻，不能只说「有 1 小时时差」**。落地当天的安排要按**当地时间**重排：
    「浦东 14:45 起飞 → 关西 18:00 落地」意味着当地时间 18:00，出关取行李后进市区已是 20:00 左右，
    **落地日不要再排需要白天时段的项目**（景点闭园、租车行关门、需要预约的场次）。
  - **同一 `leg` 内各航段耗时相加应等于总行程时间**（`2h5m + 中转 4h35m + 2h15m`），
    对不上就说明时刻表抄错了或时区算错了，**这是最容易被自己糊弄过去的自相矛盾**。
  - **是否联程 / 行李直挂必须核实并写进 `flights[].note`**：不直挂则中转时间要多留 1.5–2h（取行李 + 重新值机 + 再安检）。
    中转时间 < 2h 的联程要标注风险。
  - **多人不同机（有人先返、有人从别的城市走）**：按多人并行处理，出泳道图，
    并在 `flights[].pax` 标明每段谁在飞机上——**这是 `flights[]` 存在的核心理由之一**。
  - **返程落地次日凌晨**（`00:05+1`）时，落地日**不能算作可用的一天**，次日要留恢复时间。
- **老年团 / 慢节奏**：单日强度与驾驶时长进一步下调、午休、慢性病用药与医保异地结算。
